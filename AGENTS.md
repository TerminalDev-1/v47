# Private Server

This project is Private Server, a Python private server for Brawl Stars v69. Investigate and implement the client and server components required to make the private server work. Preserve original APKs and work on separately identified copies. Verify actual client behavior and protocol details rather than assuming compatibility.

Do not assume a server codebase already exists. Inspect the workspace first; if it does not contain one, build the necessary implementation from scratch.
